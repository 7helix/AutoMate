# Changelog

## 1.2.0
- **Social hub**: one-tap shortcuts for 14 social apps, share AutoMate, 5 social recipes.
- 4 new actions: open social app/profile, share sheet with text, WhatsApp chat with text, copy to clipboard.
- Share any rule as text from the Rules screen.
- Animations: confetti on new rule / engine start, glowing ring on the running engine card, bouncy navigation icons, springy entrances, slide-up detail pages, shimmer loading, toast icon bounce.
- Two new articles: Social media automation, Social media limits.

## 1.1.0
- New **Learn** tab with 13 articles: guides, limitations, rules and policies (searchable, shareable).
- Rule editor shows "Learn more" hints for Android limits.
- Docs live in `docs/` and are shared by the app and GitHub.
- Fixed the GitHub build workflow (removed the failing setup-android step).
- Added LICENSE, CONTRIBUTING, CODE_OF_CONDUCT, SECURITY and issue templates.

## 1.0.0
- First release: rules engine, 11 triggers, 8 actions, 4 themes, animations, toasts, settings, activity log.
