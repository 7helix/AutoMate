# Keeping the engine running

Some phone makers close background apps aggressively. These steps help.

## Do these first
1. Open **Settings > Permissions** in AutoMate and allow everything you use.
2. Set battery to **Unrestricted** (the "Unrestricted battery" row).
3. Allow **Notifications** so the engine notice stays visible.

## If it still stops
- Lock AutoMate in the recent apps list if your phone offers that.
- Turn off "adaptive battery" or "sleeping apps" features for AutoMate.
- Some brands need a separate "Autostart" permission in their own settings.

## After a restart
If **Start on boot** is on and the engine was running before the restart, AutoMate tries to start it again. Some phones block this until you open the app once.

> Note: swiping the app away from recent apps stops the engine on some phones. Use the **Stop** button in the notification when you want to stop it on purpose.
