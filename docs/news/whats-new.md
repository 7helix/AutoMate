# What's new in 1.3

## Smarter rules
- **Conditions**: add "only if" checks such as time window, weekdays, battery, charging, Wi-Fi, airplane mode, screen and Do Not Disturb.
- **Multiple steps**: chain up to 10 steps with optional waits between them.

## 10 new triggers
- Repeat at an interval
- Screen turns on / off
- Airplane mode turned on / off
- Wired headphones plugged in / unplugged
- Battery saver turns on / off
- Phone starts up

## 11 new actions
- Speak text aloud
- Set a volume level
- Set screen brightness
- Change Do Not Disturb
- Press a system button (Home, Back, Recents, notification shade, quick settings, lock screen, screenshot, power menu)
- Open a settings page
- Play a notification sound
- Open the camera
- Open dialer, start a text message, start an email

## New pages and tools
- **Gallery**: 24 ready-made rules in 6 categories.
- **Stats**: weekly chart, success rate, streak and top rules.
- **Phone control**: enable and test system buttons.
- **Backup and restore**, plus a **home-screen widget**.
- **Folders, search and filters** for rules, and a duplicate button.
- **Hindi** language for menus, buttons and main screens.

## Polish
- Grouped menus, safer imports with validation, and clearer messages when Android blocks something.
- Rules saved by earlier versions are upgraded automatically.
